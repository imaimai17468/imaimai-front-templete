# 0031. The Aegis process contract moves to `.claude/rules/aegis.md`, mirrored into `.cursor/rules/` as file-level symlinks

- Status: accepted
- Date: 2026-08-07

## Context

The repository owner asked for AGENTS.md's core rules and its Aegis process
sections to stop sharing one file, and for the Aegis rules to reach Cursor
sessions. Three sections were Aegis-specific: the Degraded Environments Aegis
bullet, the `deploy-adapters` warning, and the `aegis:start`/`aegis:end`
enforcement block.

Two earlier decisions blocked the obvious moves. ADR-0030 (same day) rejected
extending `.claude/rules/`, citing Claude Code loader bugs
([#16853](https://github.com/anthropics/claude-code/issues/16853),
[#16299](https://github.com/anthropics/claude-code/issues/16299)) — a MUST
placed there could be silently absent or silently always-on. ADR-0026 deleted
the `.cursor/` mirror after its copy drifted for three months undetected.

Both premises were re-measured on 2026-08-07:

- **Claude Code 2.1.223, local sentinel test.** Four rule files in a scratch
  project's `.claude/rules/`: `alwaysApply: true` with Cursor-style
  `description`; `alwaysApply: false` + unquoted single-path CSV `paths:`;
  `alwaysApply: false` + both `globs:` and multi-path CSV `paths:`; and the
  quoted YAML-array `paths:` form the issues call broken. A headless run that
  read no files loaded only the `alwaysApply: true` rule; a run that read
  matching files loaded all four. The test was then repeated with the three
  actual rule files this ADR ships (`aegis.md`, `react.md`, `design.md`) copied
  into the scratch project: the no-read run answered from `aegis.md` alone, and
  a run reading a `.tsx` and a `.css` file loaded both scoped rules. The
  silent-failure modes ADR-0030 cited did not reproduce on this version, and
  lazy path-scoping works.
- **Cursor.** It does not read `.claude/rules/` (confirmed by Cursor staff on
  the [forum](https://forum.cursor.com/t/claude-project-level-rules-not-loaded-with-the-include-third-party-toggle-enabled/157087),
  and by this session, where `react.md`/`design.md` were absent from context).
  File-level symlinks placed directly in `.cursor/rules/` are reported working
  by Cursor staff ([repro thread](https://forum.cursor.com/t/rules-in-a-symlinked-subfolder-mdc-are-not-followed-again/152918)) —
  directory symlinks are the flaky case. Not yet measured in this repository;
  it needs a window reload, which the implementing session could not perform.

## Decision

**`.claude/rules/aegis.md` (`alwaysApply: true`) carries the whole Aegis
contract**: the consultation MUST, the writing/answering procedures, the
MCP-absent degraded path, and the `deploy-adapters` warning. AGENTS.md keeps
one-line pointers where the sections stood.

**Every `.claude/rules/` file is mirrored into `.cursor/rules/<name>.mdc` as a
file-level symlink — never a copy.** A symlink cannot drift, which is the
failure ADR-0026 removed; the extension rename is what makes Cursor's loader
accept it. `react.md`/`design.md` carry dual frontmatter — `globs:` +
`alwaysApply: false` for Cursor, unquoted CSV `paths:` for Claude Code — and
both files, as written, were loaded lazily by the repeated sentinel test above.

## Alternatives considered

- **Keep everything in AGENTS.md** (the ADR-0030 status quo): rejected by the
  owner after seeing the trade-offs; the mixing itself was the complaint.
- **Regroup within AGENTS.md**: recommended first, declined — same reason.
- **A generator producing `.cursor/rules/` copies from `.claude/rules/`**:
  rejected; it reintroduces a second artifact under a second discipline, the
  ADR-0026 failure with extra machinery.

## Consequences

- This amends ADR-0030's "`.claude/rules/` is not extended" item and
  ADR-0026's deletion of `.cursor/` — copies stay banned, symlinks are not
  copies. The `deploy-adapters` ban stands unchanged.
- The Aegis MUST now depends on Claude Code's rules loader — the risk ADR-0030
  named. It is accepted on the strength of the local measurement, and a loader
  regression would now silence the contract in Claude Code sessions too, not
  only in Cursor. AGENTS.md's pointer is the only always-on trace that would
  reveal the absence.
- Cursor sessions gain the Aegis contract and the path-scoped rules for the
  first time since ADR-0026 — pending the reload-and-verify this session could
  not do. Until verified, treat Cursor loading as reported, not established.
- AGENTS.md no longer contains the `aegis:start`/`aegis:end` markers. What a
  `deploy-adapters` run does to a marker-less AGENTS.md has not been executed
  here; ADR-0026 records it appending a second copy to marker-less `CLAUDE.md`.
